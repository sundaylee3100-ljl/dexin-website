## 项目简介

上海德莘汽车工程技术有限公司（DEXIN Automotive Engineering Technology (Shanghai) Co., Ltd.）官方网站。公司成立于2009年，专注于汽车白车身制造工艺规划、机器人滚边系统、仿真离线编程及系统集成。

## 本地开发

```bash
# 克隆项目
git clone https://github.com/sundaylee3100-ljl/dexin-website.git

# 进入目录
cd dexin-website

# 使用任意HTTP服务器启动
# 例如使用Python
python -m http.server 8080

# 或使用Node.js
npx serve .
```
