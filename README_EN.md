# DEXIN Automotive Engineering Technology (Shanghai) Co., Ltd.

[中文版](README.md)

## Introduction

Official website of DEXIN Automotive Engineering Technology (Shanghai) Co., Ltd. Founded in 2009, the company specializes in automotive body-in-white (BIW) manufacturing process planning, robot hemming systems, simulation & offline programming, and system integration.

## Website

- 🌐 Main Site: https://dexin-sh.com
- 🔗 GitHub: https://github.com/sundaylee3100-ljl/dexin-website
